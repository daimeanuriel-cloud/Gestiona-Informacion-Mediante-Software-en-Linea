# Gestiona-Informacion-Mediante-Software-en-Linea
Repositorio para ejercicios y pruebas de la materia Gestiona Informacion Mediante Software en Linea

Que es GitHub
GitHub es una plataforma de alojamiento en la nube que permite a los desarrolladores almacenar, gestionar y realizar un seguimiento de los cambios en su código de programación. Utiliza Git, un sistema de control de versiones de código abierto creado por Linus Torvalds, que permite que varias personas trabajen en un mismo proyecto simultáneamente sin sobrescribir el trabajo de los demás.

Desde su adquisición por Microsoft en 2018, GitHub ha evolucionado para integrar herramientas de automatización, seguridad y gestión de proyectos, convirtiéndose en el estándar de la industria para el desarrollo de software tanto de código abierto (open source) como privado.

Caracteristicas
-Repositorios: Espacios digitales donde se almacena el proyecto completo, incluyendo archivos, imágenes, documentación e historial de cambios.
-Forking (Bifurcación): Permite a un usuario copiar un repositorio existente para experimentar con cambios sin afectar el proyecto original.
-Pull Requests: Es la forma en que un desarrollador propone cambios a un proyecto. Otros colaboradores pueden revisar el código, comentarlo y, si es correcto, fusionarlo (merge) con la rama principal.
-GitHub Actions: Herramienta potente para la Integración y Despliegue Continuo (CI/CD), que permite automatizar tareas como pruebas de software y publicación de aplicaciones.
-GitHub Pages: Servicio que permite alojar sitios web estáticos directamente desde un repositorio (ideal para portafolios o documentación).
-Gists: Pequeños fragmentos de código o notas que se pueden compartir de forma rápida.

Ventajas
-Colaboración Global: Facilita que desarrolladores de cualquier parte del mundo contribuyan a un proyecto.
-Control de Versiones Impecable: Permite regresar a cualquier punto anterior del desarrollo si algo sale mal, evitando la pérdida de datos.
-Documentación y Seguimiento: Incluye herramientas para reportar errores (Issues) y organizar tareas (Projects), manteniendo el flujo de trabajo estructurado.
-Portafolio Profesional: Funciona como un currículum vivo; los reclutadores suelen revisar el perfil de GitHub de un candidato para ver la calidad de su código y su constancia.
-Integración: Se conecta con casi todas las herramientas modernas de desarrollo (VS Code, Slack, Azure, AWS, etc.).

Desventajas
-Curva de Aprendizaje: Para principiantes, entender la lógica de Git (comandos como push, pull, commit y merge) puede ser confuso al principio.
-Privacidad en Planes Gratuitos: Aunque GitHub permite repositorios privados gratis, algunas funciones avanzadas de seguridad y análisis están reservadas para las versiones de pago (Enterprise).
-Dependencia de la Nube: Al ser un servicio centralizado, si los servidores de GitHub experimentan una caída, el flujo de trabajo colaborativo puede detenerse temporalmente (aunque el código local siga disponible).
-Riesgos de Seguridad: Si un desarrollador sube accidentalmente información sensible (como contraseñas o llaves de API) a un repositorio público, esta queda expuesta instantáneamente.
